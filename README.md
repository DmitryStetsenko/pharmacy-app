# 🟢 Pharmacy-App (Аптека — Сервіс замовлення ліків та аналізу симптомів)

Це навчальний клієнт-серверний вебзастосунок для пошуку, фільтрації, онлайн-замовлення медикаментів та симптоматичного аналізу захворювань за допомогою штучного інтелекту. Проєкт побудовано з використанням сучасних технологій, модульної архітектури та контейнеризації.

## 🤖 Функціонал ШІ (Аналізатор симптомів)
У застосунок інтегровано **Аналізатор симптомів** на базі моделі **Gemini 2.0 Flash**. Користувач може обрати симптоми або описати своє самопочуття, а ШІ проведе попередній аналіз, підбере можливі категорії захворювань та порекомендує ліки з каталогу аптеки (із попередженням, що аналіз є лише ознайомчим і не замінює візит до лікаря).

## ⚙️ Налаштування API Ключа Gemini
Для роботи аналізатора симптомів потрібен безкоштовний API-ключ:
1. Перейдіть на сторінку [Google AI Studio](https://aistudio.google.com/) та згенеруйте API-ключ (формат `AIzaSy...`).
2. У директорії `backend/` створіть або відредагуйте файл `.env`.
3. Додайте туди ваш ключ:
   ```env
   GEMINI_API_KEY=ваш_отриманий_ключ
   ```

## 🛠️ Технологічний Стек

### Клієнтська частина (frontend):
*   **Next.js 16 (App Router)** & React 19 (TypeScript)
*   **Feature-Slice Design (FSD)** — архітектурна методологія
*   **Ant Design v5** — бібліотека компонентів та дизайн-система
*   **Redux Toolkit (RTK)** — управління глобальним станом (кошик, тема)
*   **RTK Query** — кешування та виконання API запитів
*   **NextAuth.js** — автентифікація та сесії користувачів

### Серверна частина (backend):
*   **Node.js & Express** (TypeScript)
*   **Gemini API (Google Gen AI SDK)** — інтеграція ШІ-аналізатора (`gemini-2.0-flash`)
*   **JWT & Bcrypt** — авторизація запитів та безпечне хешування паролів
*   **Swagger (Swagger UI)** — документація та інтерактивне тестування API
*   **Helmet & CORS** — заголовки безпеки та розмежування ресурсів
*   **Express Rate Limit** — захист від брутфорсу та спаму
*   **In-Memory Storage** — імітаційна база даних у оперативній пам'яті

## 🚀 Швидкий запуск

### Запуск через Docker Compose (Рекомендований)
Переконайтеся, що на комп'ютері запущено **Docker Desktop**, а в файлі `backend/.env` прописано ваш `GEMINI_API_KEY`. Після цього виконайте в терміналі кореня проєкту:
```bash
docker compose up --build
```
*   **Клієнтська частина**: [http://localhost:3000](http://localhost:3000)
*   **Документація API (Swagger)**: [http://localhost:5000/api-docs](http://localhost:5000/api-docs)

### Локальний запуск (Режим розробки)
Якщо ви хочете вносити зміни та бачити їх миттєво:

1.  **Запуск Бекенду**:
    Переконайтеся, що прописали `GEMINI_API_KEY` у `backend/.env`.
    ```bash
    cd backend
    npm install
    npm run dev
    ```
2.  **Запуск Фронтенду**:
    ```bash
    cd frontend
    npm install
    npm run dev
    ```
