# Інструкція з розгортання та запуску (Deployment)

Цей проєкт можна запустити двома способами: за допомогою **Docker Compose** (рекомендований для продакшн-демонстрації) або **локально в режимі розробки** (рекомендовано для редагування коду).

---

## 🐋 Спосіб 1: Запуск через Docker Compose (Рекомендований)
Усі сервіси контейнеризовані та зв'язані в одну локальну мережу.

### 📋 Вимоги:
*   Встановлений та запущений **Docker Desktop**.

### 🚀 Запуск:
Перейдіть у кореневу директорію проєкту та виконайте команду:
```bash
docker compose up --build
```

Після запуску сервіси будуть доступні за адресами:
*   **Сайт (Фронтенд)**: [http://localhost:3000](http://localhost:3000)
*   **Бекенд (Swagger API Документація)**: [http://localhost:5000/api-docs](http://localhost:5000/api-docs)

### 🛑 Зупинка:
Для зупинки контейнерів натисніть `Ctrl + C` у терміналі, або запустіть:
```bash
docker compose down
```

---

## 💻 Спосіб 2: Локальний запуск (Без Docker)
Цей спосіб використовується для швидкої розробки та гарячої заміни коду (Hot Reload).

### 📋 Вимоги:
*   Встановлений **Node.js** (LTS версія).

### 🚀 Запуск Бекенду (API):
1.  Перейдіть у папку `backend/`:
    ```bash
    cd backend
    ```
2.  Встановіть залежності та запустіть dev-сервер:
    ```bash
    npm install
    & npm run dev
    ```
    *Сервер запуститься на порту 5000.*

### 🚀 Запуск Фронтенду (Клієнт):
1.  Відкрийте друге вікно терміналу та перейдіть у папку `frontend/`:
    ```bash
    cd frontend
    ```
2.  Встановіть залежності та запустіть dev-сервер:
    ```bash
    npm install
    & npm run dev
    ```
    *Клієнт запуститься на порту 3000 (або 3001, якщо 3000 зайнятий).*

---

## ⚙️ Екологічні змінні (.env)
Обидва сервіси використовують конфігураційні файли `.env` для налаштування портів, секретів JWT та лімітів.

### Для Бекенду (`backend/.env`):
*   `PORT` — порт сервера (за замовчуванням `5000`).
*   `JWT_SECRET` — ключ підпису сесії JWT.
*   `RATE_LIMIT_WINDOW_MS` — вікно обмеження частоти запитів.
*   `RATE_LIMIT_MAX` — максимальна кількість запитів за вікно.

### Для Фронтенду (`frontend/.env.local`):
*   `NEXTAUTH_SECRET` — секрет для шифрування сесій NextAuth.
*   `NEXT_PUBLIC_API_URL` — посилання на бекенд API (наприклад, `http://localhost:5000`).
