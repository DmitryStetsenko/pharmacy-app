# Загальний огляд проєкту (Pharmacy-App)

Цей проєкт є клієнт-серверним вебзастосунком для замовлення ліків в аптеці. Проєкт розроблено як навчальну роботу та структуровано за сучасними стандартами веброзробки.

## 🎯 Мета проєкту
Створення зручного інтерфейсу для користувачів для пошуку, фільтрації та замовлення медикаментів, а також панелі адміністратора для керування асортиментом ліків та перегляду замовлень.

## 🚀 Основний технологічний стек
Проєкт розділено на два основних сервіси:
1.  **Фронтенд (Клієнтська частина)**: Next.js (версія 16, App Router), React 19, TypeScript, Ant Design v5 для інтерфейсу, Redux Toolkit та RTK Query для управління станом і запитів, NextAuth.js для автентифікації.
2.  **Бекенд (Серверна частина)**: Node.js, Express, TypeScript, Swagger для документації API, Helmet & CORS для безпеки, JSON Web Tokens (JWT) для авторизації, та імітаційне сховище даних у пам'яті (In-Memory DB).

## 📂 Архітектурний паттерн
Фронтенд спроєктовано за методологією **Feature-Slice Design (FSD)**, яка допомагає розділити кодову базу на незалежні модулі, роблячи проєкт масштабованим та легким для підтримки.

*   `app/` — ініціалізація додатку, глобальні провайдери, стилі та конфігурації роутів.
*   `pages-flat/` — логічні компоненти сторінок, які імпортуються в маршрути Next.js.
*   `widgets/` — великі самостійні блоки інтерфейсу (наприклад, Header, Footer, Breadcrumbs).
*   `entities/` — бізнес-сутності проєкту (моделі та API для Medicine, Order, User, Theme, Cart).
*   `shared/` — спільні перевикористовувані компоненти, API-клієнт та допоміжні утиліти.
*   `middleware.ts` — проміжне ПЗ для захисту роутів та перевірки ролей.
