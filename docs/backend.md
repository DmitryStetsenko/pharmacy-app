# Документація Бекенду (backend)

Серверна частина проєкту реалізована на платформі **Node.js** з використанням фреймворку **Express** та мови **TypeScript**.

## 🛠️ Технологічний стек
*   **Express**: Легковажний веб-фреймворк для створення REST API.
*   **TypeScript**: Сувора типізація запитів, відповідей та моделей даних.
*   **Swagger (`swagger-jsdoc` / `swagger-ui-express`)**: Автоматична генерація та візуалізація інтерактивної документації API.
*   **Безпека**:
    *   `jsonwebtoken` (JWT) — автентифікація запитів.
    *   `bcryptjs` — безпечне хешування паролів.
    *   `helmet` — захист заголовків HTTP.
    *   `cors` — дозволяє запити з клієнтського порту.
    *   `express-rate-limit` — захист від Bruteforce-атак та обмеження частоти запитів.
*   **Валідація**: `express-validator` для перевірки тіла запитів (email, довжина пароля, коректність полів замовлення).

## 🛡️ Проміжне програмне забезпечення (Middlewares)
1.  **`authMiddleware`**: Перевіряє наявність валідного JWT у заголовку запиту `Authorization`. Якщо токен правильний, додає дані користувача у об'єкт `req.user`.
2.  **`roleMiddleware`**: Дозволяє обмежувати доступ до певних ендпоінтів залежно від ролі користувача (наприклад, тільки для `admin`).
3.  **`errorHandler`**: Словлює всі критичні помилки під час виконання запитів та повертає структуровану JSON-відповідь клієнту із відповідним HTTP-статусом.

## 🔗 Список REST API ендпоінтів

| Метод | Маршрут | Опис | Доступ |
| :--- | :--- | :--- | :--- |
| **POST** | `/api/auth/register` | Реєстрація нового користувача | Публічний |
| **POST** | `/api/auth/login` | Вхід користувача (повертає JWT-токен) | Публічний |
| **GET** | `/api/medicines` | Отримання списку ліків (з фільтрацією та пошуком) | Публічний |
| **GET** | `/api/medicines/:id` | Детальна інформація про конкретний препарат | Публічний |
| **POST** | `/api/medicines` | Додавання нових ліків до каталогу | Тільки Адмін |
| **PUT** | `/api/medicines/:id`| Редагування інформації про ліки | Тільки Адмін |
| **DELETE**| `/api/medicines/:id`| Видалення ліків з каталогу | Тільки Адмін |
| **POST** | `/api/orders` | Створення нового замовлення ліків | Авторизований |
| **GET** | `/api/orders` | Перегляд замовлень (користувач бачить свої, адмін — усі) | Авторизований |
| **POST** | `/api/symptoms/analyze-mvp` | Аналіз симптомів користувача за допомогою Gemini ШІ | Публічний |

## 🤖 Інтеграція зі штучним інтелектом (Gemini AI)
Для функціонування модуля "Аналізатор симптомів" бекенд використовує бібліотеку `@google/genai` для взаємодії з моделлю **Gemini 2.0 Flash**.
*   **Маршрут**: `/api/symptoms/analyze-mvp`
*   **Вхідні дані**: масив симптомів, обраних користувачем, або вільний текстовий опис скарг.
*   **Змінна оточення**: Сервер потребує ключ `GEMINI_API_KEY` в файлі `.env`, щоб авторизувати запити до сервісів Google AI.

## 📚 Інтерактивна документація Swagger
Swagger підключено і налаштовано за адресою `/api-docs`. Він дозволяє розробнику тестувати роботу REST API безпосередньо з браузера.
