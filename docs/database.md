# База даних (Database)

Оскільки проєкт спроектований як легковажна демонстраційна та навчальна робота, для спрощення розгортання та відсутності додаткових залежностей (таких як PostgreSQL чи MongoDB) база даних реалізована в **оперативній пам'яті (In-Memory)**.

Серверний стан зберігається в об'єктах у пам'яті всередині файлу `backend/src/db.ts` і скидається до початкових значень при перезапуску сервера бекенду.

---

## 📋 Схеми даних (TypeScript інтерфейси)

### 1. Користувач (User)
```typescript
interface User {
  id: string;          // Унікальний ідентифікатор (UUID)
  email: string;       // Унікальна адреса електронної пошти
  passwordHash: string;// Хеш пароля (bcrypt)
  role: 'user' | 'admin'; // Роль у системі
}
```

### 2. Лікарський препарат (Medicine)
```typescript
interface Medicine {
  id: string;          // Унікальний ідентифікатор
  name: string;        // Назва препарату
  description: string; // Детальний опис показань та застосування
  price: number;       // Вартість в гривнях
  inStock: number;     // Кількість залишку на складі в аптеці
  category: string;    // Категорія (напр., Знеболювальні, Вітаміни тощо)
  manufacturer: string;// Виробник ліків
  image?: string;      // Посилання на зображення ліків (або base64)
}
```

### 3. Замовлення (Order)
```typescript
interface OrderItem {
  medicineId: string;  // ID купленого препарату
  name: string;        // Назва на момент купівлі (для збереження в чеку)
  price: number;       // Ціна на момент замовлення
  quantity: number;    // Кількість одиниць
}

interface Order {
  id: string;              // Номер замовлення
  userId: string | null;   // ID користувача (null для гостьових замовлень)
  customerName: string;    // Ім'я замовника
  phone: string;           // Контактний телефон
  email: string;           // Email
  items: OrderItem[];      // Список замовлених ліків
  totalAmount: number;     // Загальна вартість замовлення
  status: 'pending' | 'completed' | 'cancelled'; // Статус обробки
  createdAt: string;       // Дата та час створення
}
```

## 🌱 Початкові дані (Seeding)
При старті додатка база автоматично наповнюється 15 видами медикаментів різних категорій для демонстрації роботи фільтрів, пошуку та кошика:
*   **Категорії**: Серцево-судинні, Знеболювальні, Застуда та грип, Вітаміни, Антибіотики, Шлунково-кишкові.
*   **Приклади товарів**: Аспірин, Парацетамол, Ібупрофен, Амоксицилін, Но-шпа, Панкреатин, Вітамін C тощо.
*   Також автоматично створюється тестовий користувач-адміністратор для перевірки панелі керування.
